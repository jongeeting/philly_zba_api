## Methodology Improvements

### Initial Approach (60 projects extracted, 6%)
- Simple digit-only regex patterns
- Matched "X parking spaces" or "X dwelling units"

### Advanced Approach (218 projects extracted, 22%)
- **Word-to-number conversion:** "THREE (3)" → 3, "FIVE" → 5
- **Multiple pattern types:** Direct digits, word+digit, word-only
- **Context-aware matching:** "TWENTY-SIX (26) DWELLING UNITS"
- **Comprehensive parking terms:** accessory, off-street, vehicular, surface, structured, interior, exterior
- **Quality filters:** Excluded ratios >5.0 (obvious extraction errors)

**Result:** 3.6x improvement in extraction (60 → 218 projects)

### Extraction Code Examples

```python
# Word-to-number mapping
NUMBER_WORDS = {
    'THREE': 3, 'FIVE': 5, 'TEN': 10, 'TWENTY': 20,
    'TWENTY-SIX': 26, 'THIRTY': 30, 'NINETY': 90, ...
}

# Pattern matching
r'(\d+)\s*DWELLING\s*UNITS?'  # "26 DWELLING UNITS"
r'TWENTY-SIX\s*\((\d+)\)\s*UNITS?'  # "TWENTY-SIX (26) UNITS"
r'(\d+)\s*(?:ACCESSORY\s+)?PARKING\s*SPACES?'  # "3 ACCESSORY PARKING SPACES"
```

## What We Still Cannot Determine

### 1. Location/Access vs. Minimum Issues

Even with parking ratios, we cannot definitively separate:
- **Parking minimums** - Developer wants less parking than code requires
- **Location rules** - Front yard prohibition, setback requirements
- **Access standards** - Curb cut width, driveway dimensions

**However:** Projects with <1.0 ratio strongly suggest minimum issues, since:
- Location/access issues don't correlate with low parking ratios
- If providing ≥1.0 ratio anyway, minimums aren't the barrier
- <1.0 ratio = revealed preference for less parking

### 2. District-Specific Minimum Requirements

Philadelphia parking minimums vary by:
- Zoning district (RSA vs RM vs CMX)
- Project size (units per building)
- Bedroom count
- Overlays and special districts

We don't have a comprehensive table of district-specific minimums to compare against.

### 3. The Other 78% of Appeals

For the 78% where we couldn't extract ratios, we don't know:
- How many have low parking ratios
- How many are minimum vs. location issues
- Whether our 22% sample is representative

**Conservative assumption:** Our sample likely over-represents clear parking minimum cases (where developers specified exact numbers). True below-minimum rate could be higher or lower.

## Data Sources and Methodology

**Primary data source:** Philadelphia CARTO API, appeals dataset
- Table: `appeals`
- Filter: `applicationtype IN ('RB_ZBA', 'Zoning Board of Adjustment')`
- Date range: 2013-01-01 to 2025-12-31
- Query: Multifamily projects mentioning parking

**Multifamily identification:**
- Regex: `\d+\s*(?:dwelling|family|unit)` (unit counts)
- Regex: `duplex|triplex|fourplex|sixplex` (building types)
- Keyword: "multi-family" or "multifamily"

**Parking extraction:**
- Regex patterns for digits: `(\d+)\s*PARKING\s*SPACES?`
- Word-to-number conversion: `THREE (3)` → 3
- Multiple parking terms: accessory, off-street, vehicular, surface, structured
- Quality filter: Ratios 0-5.0 only (exclude extraction errors)

**Unit extraction:**
- Regex patterns: `(\d+)\s*DWELLING\s*UNITS?`, `(\d+)\s*FAMILY\s*DWELLING`
- Word-to-number: `TWENTY-SIX (26) UNITS` → 26
- Range filter: 2-200 units (exclude single-family and obvious errors)

**Limitations:**
- 22% extraction rate (218/1,002 appeals)
- Cannot distinguish minimum vs. location/access from text alone
- Some projects may state parking in attachments/plans only
- Multifamily permit estimate (~20% of all permits) is rough
