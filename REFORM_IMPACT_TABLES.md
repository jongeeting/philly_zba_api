# Reform Impact Analysis (2013-2025)

**Analysis Period:** Post-2012 reform through 2025 (13 years, 16,938 appeals)

**REVISED TIER DEFINITIONS** (matching state zoning reform bills):
- **Tier 1**: Allow 4 stories by-right + Allow **duplexes (≤2 units)** + Eliminate parking minimums
- **Tier 2**: Adds Roof decks by-right + Allow **fourplexes (≤4 units)** + Expand commercial/mixed-use

## Summary: What Would These Reforms Achieve?

### Tier 1 Reforms (4 Stories + Duplex + Parking)
**Conservative estimate**: Eliminate **120 appeals/year** (9.2% of total)
- Reduces current 1,303 appeals/year → 1,183 appeals/year
- Improves by-right rate from 83.2% → 84.7% (+1.5 points)

**Optimistic estimate**: Impact **276 appeals/year** (21.2% of total)
- Some of the "partially helped" might convert to by-right
- Could reach 85-86% by-right rate

### Tier 1 + Tier 2 Combined (+ Roof Decks + Fourplex + Commercial)
**Conservative estimate**: Eliminate **661 appeals/year** (50.7% of total)
- Reduces current 1,303 appeals/year → 642 appeals/year
- Improves by-right rate from 83.2% → **91.7%** (+8.5 points!)

**Optimistic estimate**: Impact **688 appeals/year** (52.8% of total)
- Could reach 92% by-right rate
- Only ~8% of projects would need variances

### Key Insight: Tier 2 is Critical
- **Tier 1 alone**: Modest impact (9.2% eliminated)
- **Tier 1 + Tier 2**: Transformative impact (50.7% eliminated)
- **Roof decks are the game-changer**: Account for most of Tier 2's impact

### Comparison to State Zoning Reform Bills
These tier definitions match pending state legislation:
- **Duplex allowances**: Aligns with state "missing middle" housing proposals
- **Fourplex allowances**: Matches state bills for gentle density increases
- **Analysis supports state reform talking points**: Shows dramatic variance reduction potential

## Methodology Notes

**Data Source:** 16,938 ZBA appeals from 2013-2025 (post-reform period)

**Detection Method:** Keyword-based extraction from appeal descriptions
- Height: Regex pattern for "X stories" or "X floors"
- Dwelling units: Patterns for "X dwelling/family/units"
- Parking: Keyword "parking"
- Roof deck: Keywords "roof deck"
- Commercial: Keywords like "commercial," "retail," "office," etc.

**Classification:**
- **Completely Eliminated**: Appeals where reforms address ALL detected issues (single-issue)
- **Partially Helped**: Appeals where reforms address SOME but not all issues (multi-issue)
- **Total Impacted**: Complete + Partial

**Limitations:**
- Keyword detection may miss some appeals or misclassify
- "Partially helped" may or may not convert to by-right (depends on project)
- Conservative estimates focus on "completely eliminated" only
- Some appeals have no detectable issues in text (included in "Not Helped")

**Reform Definitions (REVISED):**
- **Tier 1**: Height ≤4 stories, Units ≤2 (duplex), Parking elimination
- **Tier 2**: Adds Roof decks, Units ≤4 (fourplex), Commercial/mixed-use allowances

**Why These Definitions?**
- Aligns with pending state zoning reform bills
- Duplex/fourplex matches "missing middle" housing policy proposals
- Provides talking points for state legislative advocacy
- More conservative than original triplex/sixplex analysis but still shows strong impact
