## Why the ~6 Point Baseline Difference?

Both datasets show the SAME improvement trend, but different baselines:

|  | City Table 1 | Our Analysis | Difference |
|--|--------------|--------------|------------|
| Old Code by-right | 73.4% | 79.7% | +6.3 points |
| New Code by-right | 75.7% | 82.4% | +6.7 points |
| **Improvement** | **+2.2** | **+2.7** | **✓ 0.5 pts** |

**Likely explanations:**
1. **Incomplete/withdrawn applications**: City may include applications that were started but never completed
2. **Special exceptions handling**: Different categorization approaches
3. **Procedural appeals**: City may count procedural/administrative appeals differently
4. **Data extraction timing**: City's 2017 pull vs our 2026 pull may have different completeness

**Key insight**: The ~6 point baseline difference is **consistent** (doesn't affect improvement calculation), suggesting systematic data handling difference, not random error.
