# COMPARISON: Our Analysis vs. City's 5-Year Report

## KEY FINDING FROM CITY REPORT (Page 6, Table 1):

**"Since the implementation of the new zoning code, there has been a slight increase 
in the share of permits that have been approved by right. In the four years immediately 
preceding the implementation of the new code, 68 percent of all decisions were to 
approve an application without an appeal; in the four years following the implementation 
of the new code, this share increased to 72 percent."**

### City's Numbers:
- **Old Code (8/22/08-8/21/12): 68% by-right**
- **New Code (8/22/12-8/21/16): 72% by-right**
- **Improvement: +4 percentage points**

*Note: Report highlights (page 4) claim "6 percentage point increase" but detailed 
table shows +4 points (68% to 72%).*

### Our Numbers (Using Exact Same Periods):
- **Old Code (8/22/08-8/21/12): 78.4% by-right** (6,393 appeals, 23,262 permits)
- **New Code (8/22/12-8/21/16): 82.6% by-right** (5,393 appeals, 25,660 permits)
- **Improvement: +4.2 percentage points**

## DISCREPANCY ANALYSIS:

**Our calculation: +4.2 points**
**City's detailed table: +4 points**
**City's highlights: +6 points** ← Possible error in report

### Why the 10-point baseline difference?

|  | City Report | Our Analysis | Difference |
|--|-------------|--------------|------------|
| Old Code by-right | 68% | 78.4% | +10.4 points |
| New Code by-right | 72% | 82.6% | +10.6 points |
| Improvement | +4 | +4.2 | ✓ MATCH! |

**Possible explanations for baseline difference:**
1. **City includes withdrawn/incomplete applications** - Our query only counts completed permits
2. **City includes special exceptions separately** - We may be categorizing these differently
3. **Different appeal categorization** - City may count procedural appeals we filter out
4. **Data extraction timing** - City's 2017 data vs our 2026 extraction

**IMPORTANT: The IMPROVEMENT (+4 points) matches almost exactly!**
