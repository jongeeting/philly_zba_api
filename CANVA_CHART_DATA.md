## How to Use in Canva

1. **For Bar Charts:**
   - Copy the data table (2 columns: labels and values)
   - In Canva, add a chart element
   - Click "Import data from Google Sheets" or paste directly
   - Choose horizontal bar chart for rankings
   - Customize colors to emphasize RSA-5

2. **For Pie Charts:**
   - Use the percentage data
   - Choose donut chart for modern look
   - Add data labels showing both percentage and absolute numbers

3. **For Line Charts:**
   - Use the year-by-year data
   - Add annotations for key events (COVID dip, peak year)
   - Show trend line if available

4. **Color Scheme Suggestions:**
   - **Problem/Current:** Red/Orange (#E74C3C or #E67E22)
   - **Solution/After:** Green/Blue (#27AE60 or #3498DB)
   - **Neutral/Data:** Gray (#95A5A6)
   - **Emphasis:** Bold red for RSA-5 (#C0392B)

5. **Pro Tips:**
   - Use the same color for same category across all charts
   - Make RSA-5 stand out with a different/bold color
   - Add callout text: "41% from ONE district!"
   - Use icons: house for residential, building for commercial, wrench for parking
